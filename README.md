# B+ Ark Server Controller

A Windows desktop controller for hosting and managing multiple **ARK: Survival Ascended** dedicated servers from one interface.

B+ Ark Server Controller uses a shared ARK installation to reduce disk use, while keeping each server profile’s configuration, saves, logs, backups, ports, maps, and settings separate.

## Features

- Create and manage multiple ARK server profiles
- Install, update, and verify the shared ARK server files
- Start, stop, restart, save, and monitor servers
- Live server console and RCON command console
- Map management, including modded-map support
- Mod management with load order, update checks, and CurseForge metadata
- Per-server INI editor for `Game.ini` and `GameUserSettings.ini`
- Copy selected INI setting groups between servers
- World and player-profile backups
- Scheduler, automatic updates, crash detection, and restart options
- Plugin management and plugin log viewer
- Server folder shortcuts for configuration, logs, SaveGames, mods, and plugins
- GitHub-based desktop app updates
- Theme selector and Windows system-tray support

## Installation

1. Download `BPlus-Ark-Server-Controller-setup.exe` from the latest release.
2. Run the installer.
3. Open **B+ Ark Server Controller**.
4. Install the shared ARK files from the Server Profiles page.
5. Create a server and configure its ports, map, settings, and mods.

> The controller does not start ARK automatically when it launches. Servers only start when you choose to start them.

## Requirements

- Windows 10 or Windows 11
- Enough disk space for ARK: Survival Ascended dedicated-server files
- Internet access for SteamCMD, ARK updates, and optional CurseForge mod metadata
- Administrator access may be required for firewall rules and some installation locations
